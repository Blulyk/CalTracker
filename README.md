# CalTracker

Native iOS calorie and nutrition tracker. CalTracker stores profiles, meals,
water, weight, recipes, plans and shopping lists locally with SwiftData.

Version 1.2 adds editable AI analysis, persisted meal and recipe photos,
offline restaurant lookup, buffet sessions, recipe URL import, weekly meal
planning and generated shopping suggestions.

Optional integrations:

- Google Gemini using the user's own API key stored in Keychain.
- Open Food Facts for barcode nutrition lookup.

Requirements: Xcode 26, Swift 5, iOS 17 or later.
